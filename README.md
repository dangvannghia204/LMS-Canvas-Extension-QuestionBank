**Tool này là Extension tích hợp vào trình duyệt Chrome để:**
  + Upload ngân hàng câu hỏi trắc nghiệm cho khóa học trên Canvas LMS.
  + Cập nhật ngân hàng câu hỏi trắc nghiệm liên quan đến khóa học trên Canvas LMS.
  + Tạo bài kiểm tra (Quiz) rút trích từ ngân hàng câu hỏi.
  + Giao diện thao tác giống như hình đính kèm bên dưới.
    
**LƯU Ý:** Tạo và định dạng ngân hàng câu hỏi theo file mẫu **NHCH_Mau.csv** trước khi upload lên hệ thống Canvas LMS.
